# Osa 1 – Aloitus

Tässä ensimmäisessä osassa tehdään ensimmäinen pieni Python-ohjelma.

Tavoitteena ei ole vielä rakentaa varsinaista peliä. Tutustutaan ensin siihen, miten Python-ohjelma tulostaa tekstiä.

## Tavoite

Tämän osan jälkeen osaat:

* käyttää `print()`-komentoa
* kirjoittaa Python-koodia
* käynnistää Python-ohjelman
* muuttaa valmista ohjelmaa

## Kokeile

Avaa `main.py` ja suorita ohjelma.

Ohjelma kertoo lyhyen seikkailun alun.

Katso, mitä ohjelma tulostaa.

## Tutki

Tutki `main.py`-tiedostoa.

Huomaa, että ohjelmassa on useita `print()`-komentoja.

Esimerkiksi:

```python
print("Olet saapunut pimeään metsään.")
```

`print()` näyttää tekstin ruudulla.

## Muokkaa

Muuta ohjelman tekstejä.

Esimerkiksi:

```python
print("Olet saapunut pimeään metsään.")
```

voisi muuttua muotoon:

```python
print("Olet saapunut vanhaan linnaan.")
```

Kokeile muuttaa kaikki ohjelman tekstit.

## Haaste

Kirjoita ohjelmaan vähintään kolme uutta tapahtumaa.

Esimerkiksi:

```text
Saavut linnan portille.
Portti on lukossa.
Kuulet äänen linnan sisältä.
```

Kirjoita nämä Python-koodiksi käyttäen `print()`-komentoja.

## Bonus

Tee ohjelmasta oma pieni tarina.

Voit päättää itse:

* missä pelaaja on
* mitä hän näkee
* mitä tapahtuu
* mikä ongelma pelaajalla on

Älä vielä mieti pelin sääntöjä tai valintoja.

Tässä vaiheessa rakennetaan vain tarinaa tekstin avulla.

* kirjoittaa oman pienen tarinan?
